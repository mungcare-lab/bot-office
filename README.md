나(CEO)와 AI 직원 4명이 **프로젝트 방**에서 함께 일하는 **1인 전용** AI 업무 시스템.

- **주소**: https://mungcare-lab.github.io/bot-office/
- **데이터베이스**: Supabase (Free) · 프로젝트 `ai-office` · 리전 서울(ap-northeast-2)
- **로그인**: 이메일 + 비밀번호 / 이메일 로그인 링크(매직 링크) · **관리자 1명 전용**

## 지금 되는 것 (V2.2 · 1~9단계 + 발행센터 V2.0 1~2순위)

### 계정 · 접근
- **단일 관리자 잠금** — 관리자 계정은 1개만 존재한다. 관리자가 한 명이라도 생기면 **외부 신규 가입은 DB 트리거에서 차단**되고, 로그인 화면에도 회원가입 탭이 없다. (최초 1회, 관리자가 0명일 때만 “최초 관리자 만들기”가 열린다.)
- **자동 로그인 유지** — 세션은 브라우저에 저장되고 토큰이 자동 갱신되어 새로고침·앱 재실행 후에도 로그인 상태가 유지된다.
- **피클 업무 계정(`pickle_worker`)** — 관리자가 [🔌 AI 연결 → 업무 계정]에서 발급한다. 권한은 **업무 확인 · 메시지 작성 · 피클 담당 업무의 진행률/결과 갱신**뿐이며, 예산·AI 연결/키·기억 삭제·프로젝트 생성·업무 승인/반려·긴급 정지·백업 복구는 RLS와 RPC 양쪽에서 막힌다.
- **AI 직원 무가입** — ChatGPT·Claude·Gemini·Pickle은 Auth 계정 없이 `ai_agents` 행 + 서버 연결로만 동작한다.

### 프로젝트 방 · 대화 (1~3단계 유지)
- 프로젝트 방 6개(AI OFFICE 본사 · Replay Me · 사운드오브클래식 · CROWN OF ASH · PAW PICK · 신규 사업 개발), 방마다 AI 5명(CEO 포함).
- 실시간 저장(postgres_changes), `@멘션`·`@전체` 호출, 업무 요청 모드, 파일·이미지 첨부(비공개 버킷 + 서명 URL), PWA·다크 모드, `#local` 고전 모드.

### 4단계 · 공유 기억 (유지 + 보완)
- 기억 **10분류** · 분류 칩 · 검색 · 📌 핵심 고정 · 대화 검색 → 해당 메시지 이동 · JSON 백업/복구(“복원됨” 표시).
- **중요도 1~5(P1~P5)** · **AI별 개인 업무 지침 vs 공통 기억 분리** · **변경 이력 자동 기록** · **오래된 대화 요약 저장**(규칙 기반 추출, AI 호출 없음·무료) · **중복·충돌 감지**(제목 유사도 + 같은 제목 다른 내용).
- **관련 기억 자동 선별 미리보기** — 고정 최근 N개가 아니라 ① 우선순위 ② 핵심 고정 ③ 확정 지시 ④ AI 개인 지침 ⑤ 현재 입력 키워드 ⑥ 요약 을 조합해 최대 16건·3,500자를 고른다. 시트에서 호출 문장을 넣어 결과를 미리 볼 수 있다.

### 6단계 · AI 연결 시스템
- AI별 **모델 선택**(Gemini/OpenAI/Anthropic), **개인 업무 지침**, **일일 호출 한도**.
- **연결 테스트** — 서버가 키·예산을 확인해 `connected` / `not_connected` / `blocked_budget`을 정직하게 돌려준다. 미연결이면 어떤 답변도 만들지 않는다.
- **키 관리** — 서버 환경변수 또는 `ai_provider_keys`(AES-GCM 암호문, 평문 없음). 브라우저에는 키가 없다. 키 등록은 운영자 전용(`x-admin-token`).
- **비용 관리** — 프로젝트별 일일·월간 예산, 일일 호출 한도, AI별 한도, 토큰·예상 비용 기록. **초기값은 0원/0회이며 0은 “차단”** — 키가 있어도 0원이면 호출하지 않는다.

### 7단계 · 자동 협업
- **업무(office_tasks)** — 제목·설명·우선순위(P1~P5)·담당·최대 홉. 상태: 대기/진행중/검수대기/승인완료/반려·재작업/긴급정지, 진행률 0~100%.
- **담당 자동 배정(규칙 기반)** — 조사·사실→Gemini, 분석·설계→Claude, 기획·검수→ChatGPT, 제작·실행→피클, 키워드 없으면 총괄(ChatGPT).
- **AI 작업지시 전달 카드** — 업무를 만들면 대화에 전달 카드가 남고, 미연결 AI는 “전달했지만 응답 없음(수동 대기)”으로 정확히 표시된다.
- **결과물 검수** — 승인 / 반려(재작업 사유 필수) → 재작업 → 재검수. 처리 기록(이벤트)이 남는다.
- **피클 미처리 업무** — `assigned_to='pickle'` + 대기/반려 업무를 DB 뷰(`office_pickle_tasks`)와 전용 탭으로 모아 본다. 피클 업무는 자동으로 시작되지 않는다.
- **무한 대화 방지** — 업무별 최대 홉(기본 6), 도달 시 자동 정지. 같은 idempotency key의 재전달은 중복 실행하지 않는다. 수정은 낙관적 락(`lock_version`)으로 충돌을 막는다.
- **전체 작업 긴급 정지** — 스위치 하나로 모든 프로젝트의 자동 협업·AI 호출이 즉시 멈추고 진행 중 업무가 “긴급정지”가 된다. 재개 가능.

### 9단계 · 블로그 발행센터 (V2.2 · 1~2순위 반영)
- **메뉴** — 방 목록 상단의 `📰 블로그 발행센터` 카드, 채팅방 헤더의 `📰` 버튼으로 바로 들어간다.
- **화면 전환** — `📋 발행 목록` / `👑 대표 할 일`. 대표 할 일은 대표 계정에만 보이고, **① 네이버 발행 대기 ② 콘텐츠 승인 요청 ③ 수정 사항 확인 ④ 본인인증 요청 ⑤ 비용 승인 요청**만 모은다. 원고 작성·검수·이미지·성과 기록처럼 AI·피클이 하는 일은 넣지 않는다.
- **플랫폼 탭** — `네이버` / `티스토리` / `인스타그램`을 독립 필터·관리한다.
  - **네이버** = 대표 직접 발행. 제목·본문(마크다운 제거)·서식 포함·해시태그 **원터치 복사**, 이미지 순서 배지·삽입 위치·개별/일괄 저장, 전체 미리보기, 글쓰기 바로가기, 발행 완료+URL 등록. 자동 로그인·자동 게시는 없다.
  - **티스토리·인스타그램** = **대표는 복사·붙여넣기를 하지 않는다.** 대표 승인 후 **피클이 플랫폼 정상 웹 UI로 발행**하고 URL·성과를 기록한다. 수동 복사 도구는 자동 발행이 막혔을 때만 쓰는 비상용(접힌 영역)으로 내렸다.
- **8단계 상태** — 기획 중 · 자료 조사 중 · 원고 작성 중 · 이미지 제작 중 · 검수 중 · 수정 요청 · 발행 대기 · 발행 완료. **승인(발행 대기)은 대표 전용**이고, 승인 후 **발행 완료·URL 기록은 피클도 가능**하다(승인 전환·승인 취소·발행 URL 변경은 계속 차단). 서버 트리거·RLS·RPC 3중으로 강제한다.
- **SEO 자체 점검 V1.0 (티스토리)** — **콘텐츠 유형 8종 + 일반 정보형**별 권장 분량(공백 제외)을 적용하고 **9개 항목 100점**(검색 의도 20 · 정보 정확성·출처 20 · 독창성·실용성 20 · 제목·본문 구조 10 · 모바일 가독성 10 · 키워드 자연스러움 5 · 이미지·대체 텍스트 5 · 내부·외부 링크 5 · 유형별 적정 분량 5)으로 계산한다. 화면에 "AI OFFICE 내부 콘텐츠 품질 점검 점수이며 실제 구글 검색 순위 평가와는 무관합니다."를 명시한다.
  - 유형은 글의 `content_type`으로 저장하고, 비어 있으면 **제목 → 카테고리** 순으로 자동 연결한다. 상세 화면의 [콘텐츠 유형] 선택으로 언제든 바꿀 수 있다.
  - **일률적 '1,200자 이상' 기준은 폐기**. 분량 미달은 9번째 항목에서 최대 2점만 감점하며 **발행을 차단하지 않는다**. 보류는 사실관계 오류·저작권 문제·개인정보 노출 같은 **중대한 검수 문제(검수 7항목의 '중대')**뿐이다.
  - 참고 지표(제목 길이·본문 분량·키워드 등장·메타 설명·해시태그·이미지)는 합격/불합격이 아닌 참고용으로 함께 보여 준다.
- **콘텐츠 검수 체크리스트(7항목)** — 허위·과장 표현, 실제 사용 경험 vs 일반 정보, AI 요금·기능 최신성, 개인정보·계정 노출, 이미지 저작권, 구축비(0원) vs AI 사용 비용, 실제 연결 AI vs 연결 예정 AI. 원고를 자동 스캔해 힌트를 보여 주고, 사람이 **확인/보완 필요/해당 없음**과 메모를 저장한다. 미확인 항목이 있으면 승인 전에 경고한다(승인 자체를 막지는 않음).
- **발행 관리** — 발행 예정 **날짜·시간** 표시, 예정 시각이 지난 콘텐츠의 **지연 표시**, 발행 URL **정상 작동 확인**(브라우저 보안으로 상태 코드를 못 읽으면 '제한'으로 정직하게 표시), **발행 실패 사유 기록**, **중복 발행 방지**(같은 URL은 한 콘텐츠에만, 서버 유니크 인덱스+RPC), **수정 이력 자동 보관과 복원**.
- **콘텐츠 완성본** — 게시 예정 날짜·시간, 플랫폼, 카테고리, 핵심 키워드, 검색 의도, 제목, 본문, 대표 이미지, 본문 이미지(순서·삽입 위치·대체 텍스트·라이선스·출처), 해시태그, 참고 출처, 정보 확인 날짜, 검수 결과, 실제 발행 URL, SEO 필드. 이미지는 비공개 버킷(`blog-images`)에 두고 서명 URL로만 연다.
- **성과·색인은 수기 기록** — 무료 원칙상 외부 분석 API를 붙이지 않는다. 티스토리 관리자·인스타그램 인사이트에서 확인한 값을 기록하고, 색인은 서치어드바이저·서치콘솔 확인 결과를 남긴다.

### 8단계 · 외부 기억 이전
- 텍스트 붙여넣기 / JSON / Markdown / **SKILL.md** 파일을 후보 기억으로 자동 분류하고, **항목별 승인 후에만** 저장한다(자동 연동 아님을 화면에 명시).
- **악성 지시문(프롬프트 인젝션) 방어** — `ignore previous`, `system:`, `<system_msg>`, 키 출력 요구 등 패턴을 탐지해 경고하고, 외부 문서는 `<external_document>`로 격리해 AI가 지시로 실행하지 않게 한다.

## 아직 안 되는 것 (의도)
- **AI의 실제 답변** — 서버에 제공자 키를 등록하지 않았고 예산도 0원이라, 모든 AI는 “API 미연결(수동 대기)” 또는 “예산 차단”으로 표시된다. 어떤 경우에도 AI가 답한 것처럼 꾸민 메시지를 만들지 않는다(RLS가 `author_kind='ai'` 클라이언트 생성을 차단).
- 키를 등록하고 예산 한도를 0보다 크게 올리면 실제 호출이 가능하지만, 이번 범위에서는 **유료 호출을 하지 않았다.**

## 2026-11-27 채팅 개선 (복사 · 마크다운 · 공유 · 북마크 · 모바일)
- **복사** — 사용자·AI 모든 메시지에 `📋 복사` 버튼(최소 30px 높이). 전체 복사는 마크다운 기호(`#`·`**`·백틱·표 파이프)를 걷어낸 평문이고, `⋯` 메뉴에서 **마크다운 그대로 복사**도 고를 수 있다. 코드·프롬프트 블록은 블록 우측 상단 `[복사]` 버튼으로 개별 복사. 복사 결과는 하단 토스트로 알린다.
- **길게 누르기(~450ms)** — 드래그·스크롤(10px 이동)과 충돌하지 않게 취소되고, 손가락을 떼는 순간의 클릭이 배경에 닿아 시트가 바로 닫히지 않도록 450ms 가드를 둔다. 메뉴: 복사 · 마크다운 그대로 · 공유 · 북마크 · 부분 텍스트 선택 · 프로젝트 기억으로 저장 · 업무 지시서로 등록 · 다른 방으로 전달.
- **부분 텍스트 선택** — `select-text` 모드에서만 글자 선택이 켜지고(그 전에는 길게 누르기가 메뉴), 하단 안내 띠의 `선택 복사`로 선택 구간만 복사한다.
- **안전한 마크다운** — 제목·굵게·기울임·목록·표·코드블록·인용·자동 링크. React 텍스트 노드로만 그려 `<script>`·`onerror=`·`onclick=` 는 글자로만 보이고 실행되지 않는다. 링크는 http/https/mailto/tel 만 허용(`javascript:`·`data:` 차단), 새 창 + `rel="noopener noreferrer"`.
- **긴 메시지 접기** — 420자 또는 14줄을 넘으면 접고 `[전체 보기 / 접기]` 토글. 표·코드는 말풍선 안에서만 가로 스크롤(`overflow-x:auto`)하고 페이지 전체는 가로로 넘치지 않는다.

- **기억 저장·업무 등록** — 반드시 확인 시트(제목·유형·중요도 / 제목·지시 내용·우선순위·담당)를 거친 뒤 `project_memories`(source_message_id 기록)와 `office_tasks` 에 저장한다. 등록 시 AI 를 자동 호출하지 않는다.

- **모바일** — 헤더를 2줄(이름 2줄 허용 + 도구 칩 줄)로 정리해 이름이 잘리지 않는다. 새 시트는 모두 `pushState`/`popstate` 스택에 들어가 **안드로이드 뒤로가기 = 닫기**(기억 시트에서 뒤로가면 작업 메뉴로). 방을 오갈 때 **방별 스크롤 위치를 기억·복원**한다.
